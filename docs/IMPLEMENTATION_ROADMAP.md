## Sequencing rule used

Each batch ends with the verification commands for the layer it touched, and the pinned figures
(`pmt 78.2 / 37.8 / 21.9 / 191,939`) are re-asserted after every engine change. A batch that moves
a pinned figure is not merged until the README, `docs/METHODOLOGY.md` and `docs/SUBMISSION.md` are
updated in the same commit, because those three files quote the same table.
